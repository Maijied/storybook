## 🚀 Interactive Features

* 🐛 **Vaultie 3D Rigged Mascot:** Procedural breathing waves, blinking expressive eyes, cursor tracking, typing claws, and interactive emote buttons (`👋 Wave`, `💃 Dance`, `⚡ Turbo Typing`, `🎉 Victory Jump`, `🌱 Instar Molt`).
* 📖 **Turnable 3D Cybernetic Tome:** Three.js open holographic book with realistic 3D page flip physics and gold corner filigrees.
* 🎙️ **Speech Narration:** Built-in Web Speech API voice reader for all chapters.
* 🎵 **Procedural Audio Synthesizer:** Pure Web Audio API sound effects for page turns, chimes, and typing.
* 💻 **Interactive Cyber Terminal:** In-browser command line (`agent run`, `mcp`, `sync`, `dance`, `story 1..3`, `chapter 1..5`).
* 🎨 **Art Vault Lightbox:** High-resolution original storyboard art and illustrations.
